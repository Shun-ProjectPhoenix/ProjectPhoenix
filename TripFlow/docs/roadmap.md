# TripFlow 開発ロードマップ

## 現在地

TripFlow Desktop版 v0.6まで完成。
Web v0.1・Web v0.2・Web v0.3完成。
Web v0.4は、Phase A（Gmail認証基盤）・Phase B（Gmail検索・候補一覧表示）まで完了（実際のGmail環境での動作確認済み）。
Phase C（メール判定・予約情報抽出・登録候補表示）は、えきねっと・Agodaとも実機確認を経て解析精度を改善し、**完了・commit / push済み**。

Web v0.4 Phase D（前半）：スマートEX・スカイマークをGmail連携の対象サービスに追加する土台を実装し、4回の実機確認（スマートEXのみ）を経て、区間・時刻・列車名・号車・座席番号・予約識別情報・TARGET分類・予約補完メール分類（乗車用ICカード指定内容）が**すべて実機確認済み**となった。4回目の実機確認で料金のみ未取得だったため、料金が「領収額は、合計XXXX円です。」という文章形式で表示される構造に対応した（自動テスト完了、実機再確認待ち）。スカイマークは実メール未確認のため、Phase D前半の土台実装のまま変更していない。
