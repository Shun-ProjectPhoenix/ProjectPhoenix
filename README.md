# ✈️ TripFlow

> **すべての出張を、ひとつのアプリで。**

TripFlow は、出張に必要な情報を一元管理するための Web アプリです。

ホテル・新幹線・飛行機など、複数のサービスに分散した予約情報をまとめ、
**「予約漏れを3秒で確認できる」**ことを目指しています。

# 🚀 コンセプト

現在の出張では、

- Gmail
- えきねっと
- スマートEX
- 航空会社
- ホテル予約サイト

など、予約情報が複数のサービスへ分散しています。

TripFlow は、

> **出張情報を一つの画面にまとめる**

ことを目的として開発しています。

## 📧 Gmail連携（開発予定）

Googleアカウントと連携し、

予約メールから

- ホテル
- 飛行機
- 新幹線

を自動抽出します。

※登録前に必ず確認画面を表示します。

---

# 🎯 TripFlowが目指すこと

TripFlowは

「出張を記録するアプリ」

ではありません。

TripFlowは

> **予約漏れを3秒で確認できるアプリ**

を目指しています。

例えば、

```
福岡出張

✅ 往路

✅ ホテル

⚠ 復路未予約
```

この状態を一目で確認できます。

# 💡 開発理念

TripFlow は

「便利そうだから」

ではなく、

**自分自身が毎回の出張で本当に使いたい**

と思えるアプリを目指しています。

そのため、

- シンプル
- 分かりやすい
- 予約漏れを防げる

ことを最優先に設計しています。
